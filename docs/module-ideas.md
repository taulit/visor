# Module ideas after 1.0

Each one becomes a repo of its own (`visor-<name>`, UUID `visor-<name>@taulit.github.io`, store name "Visor: <Name>"), started from `examples/module-template/`. One slot per module.

- **Spotify controls** (Now): the track that plays in Spotify with play, pause, next and the cover.
- **GoodDay** (Up Next): today's tasks and appointments from GoodDay.
- **1Password search** (search): find an item in 1Password from the Visor search and copy a field.
- **GitHub pull requests** (Up Next): pull requests that wait for your review, and checks that failed.
- **Weather** (Up Next): the weather for the next hours at your place.
