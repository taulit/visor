## What it does

<CardGrid>
  <Card title="Now" icon="seti:video">
    Players that report through MPRIS with cover and controls, timers, alarms and stopwatches,
    running downloads and the sessions of your coding agent.
  </Card>
  <Card title="Up Next" icon="seti:clock">
    Your next calendar events with a Join button for video calls, and the notifications of the shell
    with Do Not Disturb.
  </Card>
  <Card title="One search field" icon="magnifier">
    Calculate, convert currencies and units, ask for time zones and dates, find emoji, launch apps
    and run system actions. `timer 25m Pizza` starts a timer.
  </Card>
  <Card title="Agent approvals" icon="approve-check">
    With the module [Visor: T3 Code](/visor/features/#agent-approvals-with-t3-code), the notch
    lights up when a [T3 Code](https://github.com/pingdotgg/t3code) agent wants to run a command.
    Read it and allow or deny it in the row.
  </Card>
  <Card title="Looks like GNOME" icon="setting">
    Follows the top bar, the accent colour and the light or dark style. Animations stay off when
    GNOME's animations are off.
  </Card>
  <Card title="Modules" icon="puzzle">
    Other extensions add rows, sections and dock views through a stable, frozen API. [Write a
    module](/visor/modules/).
  </Card>
</CardGrid>

## Privacy

No account, no telemetry, no server of its own. Visor makes only the requests listed on the
[privacy page](/visor/privacy/), and each of them can be turned off.
